# Credit Card Fraud Detection

## Project Overview

Credit Card Fraud Detection is a web-based academic project developed using Python, Django, and Machine Learning.

The project aims to identify potentially fraudulent credit card transactions through a web application.

## Technologies Used

- Python
- Django
- Machine Learning
- HTML
- CSS
- JavaScript

## Project Structure

- `CreditCard/` – Django project configuration
- `User/` – Application logic
- `templates/` – HTML pages
- `static/` – CSS, JavaScript, images, and dataset
- `manage.py` – Django management file
- `requirements.txt` – Python dependencies

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Narayan87921/Credit-Card-Fraud-Detection.git
   ```

2. Open the project folder:

   ```bash
   cd Credit-Card-Fraud-Detection
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

4. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Run database migrations:

   ```bash
   python manage.py migrate
   ```

6. Start the development server:

   ```bash
   python manage.py runserver
   ```

7. Open this address in your browser:

   `http://127.0.0.1:8000/`
